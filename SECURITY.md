# Security Policy

## Supported Versions

For v0.1, security support covers only the current `main` branch and the latest
public release. Older commits and releases are not covered by a long-term
support commitment.

## Reporting a Vulnerability

Do not report a suspected vulnerability in a public GitHub issue.

Prefer GitHub Private Vulnerability Reporting when the repository's
**Report a vulnerability** action is available. Otherwise, report the issue
privately to [siriusa.paper@gmail.com](mailto:siriusa.paper@gmail.com).

Include enough information to reproduce and assess the issue without including
unnecessary sensitive data. Describe the affected version or commit, relevant
environment, reproduction steps, observed impact, and any known mitigations.

Do not send credentials, tokens, private `AGENTS.md` contents, or unrelated
proprietary material unless it is necessary and has been explicitly
coordinated with the maintainer.

Reports will be assessed and, when appropriate, remediation and public
disclosure will be coordinated before details are published. No response or
fix deadline is promised.
